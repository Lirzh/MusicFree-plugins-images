## 一键安装 🚀

在 MusicFree 应用中，从网络安装插件：

```
https://gh-proxy.org/https://raw.githubusercontent.com/Lirzh/MusicFree-plugins-images/refs/heads/main/plugins.json
```

> 🛰 使用了 gh-proxy 代理加速，国内用户访问也很快～
